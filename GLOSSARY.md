# Personal Portfolio

A personal website rebuilt from public observation of the reference site, using independently written content and structure. It is a single-context portfolio, not a clone.

## Language

### Content

**Blog Post**:
An engineering article listed on the blog index and read at its own URL.
_Avoid_: Article, Entry

**Tag**:
A topic label that groups Blog Posts.
_Avoid_: Category

**Metric**:
A single measured value with a unit, source, timestamp, and history.
_Avoid_: Stat

Note: Metric `category` is a spec field (story 15 / spec #1) that groups Metrics by category — it is distinct from the Glossary `Tag` grouping above, which applies to Blog Posts.

**Dashboard**:
The public page that presents Metrics as cards and historical trends.
_Avoid_: Stats page

**Project**:
A side project, experiment, or work showcased in the portfolio.
_Avoid_: Side-Hustle

**Newsletter Issue**:
A newsletter edition listed in the index and read externally on Substack.
_Avoid_: Newsletter Post, Substack Post

### Identity

**Persona**:
The identity presented on the site — name, role, and contact.
_Avoid_: Author, Owner

**Placeholder**:
Original sample content and identity used in place of the reference site's real content.
_Avoid_: Fake, Dummy, Sample Data
