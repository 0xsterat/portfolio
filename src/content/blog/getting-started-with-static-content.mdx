Static content is a solid default for a personal site. Writing posts as Markdown keeps
the authoring flow close to the code, and it lets the build step validate everything
before deploy.

```ts
import matter from "gray-matter";
import { parseBlogPost } from "@/lib/content";

const raw = readFileSync("src/content/blog/example.mdx", "utf-8");
const { data: frontmatter, content } = matter(raw);
const post = parseBlogPost(frontmatter); // Zod-validated at build time
```
