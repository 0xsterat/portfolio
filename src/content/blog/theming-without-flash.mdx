A theme preference stored client-side only helps if the first paint already knows
it. An inline script in the document head applies the class before hydration.

```html
<script>
  (function () {
    var stored = localStorage.getItem("theme");
    document.documentElement.classList.toggle("dark", stored !== "light");
  })();
</script>
```
